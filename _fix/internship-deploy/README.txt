ДАДЛАГА / АЖЛЫН БАЙРНЫ ӨРГӨДЛИЙН МОДУЛЬ — суулгах заавар
========================================================

Юуг шийдэж байгаа вэ:
  Өмнө нь сайтын "Apply for Internship" (/page/7) болон "APPLY NOW" (/page/6)
  хэсгүүдэд ЯМАР Ч ФОРМ байгаагүй — хүмүүс зөвхөн и-мэйлээр хүсэлт илгээдэг
  байсан тул CP Admin дээр юу ч харагддаггүй байв. Одоо форм нэмэгдэж, ирсэн
  хүсэлт бүр өгөгдлийн санд хадгалагдаж, CP Admin -> "Дадлага" цэснээс
  харагдана.

Хуудасны хаяг:  https://mglenc.com/internship   (дадлага)
                https://mglenc.com/career       (ажлын байр)
                /page/7, /page/6 хуудсууд дээр ч форм автоматаар гарна.

CP Admin цэс:   "Дадлага"  ->  Ирсэн хүсэлт / Формын асуулт / Тохиргоо


1. ФАЙЛУУДЫГ БАЙРЛУУЛАХ
-----------------------
Энэ хавтасны доторх бүтцийг public_html дотор ЯГ ХЭВЭЭР нь хуулна:

  class/apply.class.php               (шинэ)
  class/xlsx.writer.class.php         (шинэ — аль хэдийн байвал алгасна)
  pages/apply/                        (шинэ хавтас)
  pages/page/sys.php                  (СОЛИНО — формыг /page/N дээр гаргана)
  pages/page/page.php                 (СОЛИНО)
  pages/page/onepage.php              (СОЛИНО)
  assets/css/apply.css                (шинэ)
  skin/new/home.php                   (СОЛИНО — apply.css нэмэгдсэн)
  cpadmin/pages/internship/           (шинэ хавтас)
  cpadmin/user.info.php               (СОЛИНО — цэс, эрх нэмэгдсэн)
  cpadmin/router.php                  (СОЛИНО — зөвхөн локал хөгжүүлэлтэд)
  .htaccess                           (СОЛИНО — /internship, /career зам)
  cpadmin/.htaccess                   (СОЛИНО — админы зам)

АНХААР: энэ багц дахь cpadmin/user.info.php болон skin/new/home.php нь энэ
репод хийгдээд байгаа БУСАД ажлыг ("Харилцагч байгууллага" цэс, ERP нэвтрэлт)
бас агуулж байгаа. Хэрэв тэдгээрийг серверт хараахан гаргаагүй бол эдгээр
хоёр файлыг бүтнээр нь солихын оронд зөвхөн доорх хэсгүүдийг нэмнэ:

  cpadmin/user.info.php  —  "$gloMenuArr[\"internship\"]" ба
                            "$adminAccessPer[\"internship\"]" гэсэн хоёр блок
  skin/new/home.php      —  "if(!empty($applyCssOn))" гэсэн CSS блок

.htaccess файлуудыг солихоос өмнө хуучныг нь нөөцлөх нь зүйтэй.
Хэрэв та өөрөө .htaccess-ээ засах бол зөвхөн доорх мөрүүдийг нэмнэ:

  public_html/.htaccess   —  "^n/([0-9]+)" мөрийн ӨМНӨ:
      RewriteRule ^internship(/?)$ index.php?incPageType=apply&applyType=intern [L,QSA]
      RewriteRule ^career(/?)$ index.php?incPageType=apply&applyType=job [L,QSA]

  cpadmin/.htaccess       —  "^registration/..." мөрүүдийн ДАРАА:
      RewriteRule ^internship/([^/]+)/([0-9]+)(/?)+$ index.php?incPageType=internship&subPage=$1&objID=$2 [L,QSA]
      RewriteRule ^internship/([^/]+)(/?) index.php?incPageType=internship&subPage=$1 [L,QSA]


2. ӨГӨГДЛИЙН САН
----------------
Юу ч хийх шаардлагагүй. CP Admin -> Дадлага хэсгийг эсвэл /internship
хуудсыг анх нээхэд дараах хүснэгтүүд АВТОМАТААР үүснэ:

  db_apply_setting   тохиргоо, бичвэрүүд
  db_apply_field     формын асуултууд
  db_apply_entry     ирсэн хүсэлтүүд

Хавсаргасан файлууд cpadmin/postpic/apply/ дотор хадгалагдана. Уг хавтас
болон түүний .htaccess (гаднаас татахыг хориглох) нь эхний файл ирэхэд
автоматаар үүснэ. Хавсралтыг зөвхөн нэвтэрсэн админ CP Admin-аас татна.


3. ХИЙХ ЗҮЙЛ (нэг удаа)
-----------------------
a) CP Admin -> Дадлага -> Тохиргоо хэсгээс бичвэрүүдээ шалгаж, хүсвэл
   өөрчилнө. "Формыг харуулах хуудсууд" талбарт өгөгдмөл нь 7 (дадлага)
   ба 6 (ажлын байр) байна — өөр хуудсанд гаргах бол ID-г нь солино.

b) CP Admin -> Дадлага -> Формын асуулт хэсгээс асуултуудаа тохируулна.
   "Хаана гарах" баганаар асуулт бүрийг дадлагын, ажлын байрны эсвэл
   хоёуланд нь гаргахыг сонгоно.

c) Хүсвэл /about хуудасны "Apply for Internship" болон "APPLY NOW"
   линкүүдийг шууд /internship, /career руу заана (CP Admin ->
   Мэдээлэл оруулах -> Агуулга оруулах). Заавал биш — /page/7, /page/6
   дээр форм гарсаар байх болно.


4. ШАЛГАХ
---------
  1. https://mglenc.com/internship нээж, форм гарч байгааг харна.
  2. Туршилтын хүсэлт илгээнэ (PDF хавсаргаж үзнэ).
  3. CP Admin -> Дадлага -> Ирсэн хүсэлт дээр тэр хүсэлт харагдана.
  4. "Харах" дарж дэлгэрэнгүй, хавсралтаа татаж үзнэ, төлөв солино.
  5. Excel татаж, баганууд бүрэн эсэхийг шалгана.
  6. Туршилтын бичлэгээ устгана.

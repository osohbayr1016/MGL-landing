БҮРТГЭЛИЙН ФОРМ — "АЖИЛ ЭРХЭЛЖ БАЙГАА" СОНГОВОЛ БАЙГУУЛЛАГЫН НЭР ЗААВАЛ — суулгах заавар
==========================================================================

Юу нэмэгдэв:
  "Ажил эрхэлж байгаа." сонгосон үед "Байгууллагын нэр" заавал бөглөх болно.
    - Сонгоход талбарын нэрийн хажууд * тэмдэг шууд гарна.
    - Хоосон илгээвэл "Заавал бөглөнө үү." алдаа гарна (сервер шалгана).
    - Сонголтоо болиулбал дахин заавал биш болно.

ХУУЛАХ (public_html дотор ЯГ ХЭВЭЭР нь, дарж хуулна):
  class/registration.class.php
  pages/registration/blocks/form.php
  assets/js/registration.js
  cpadmin/pages/registration/field.frm.php

  SQL, .htaccess, const.php — өөрчлөхгүй.
  (Өмнөх "Бүртгэл дүүрсэн" засвар энэ файлуудад хэвээр орсон.)

ТОХИРУУЛАХ:
  ШААРДЛАГАГҮЙ — файлуудыг хуулмагц шууд ажиллана. Дүрэм кодонд суусан:
  "Статус" (position) талбарын "Ажил эрхэлж байгаа." сонголт ->
  "Байгууллагын нэр" (company) талбар заавал.
  CP Admin дээр юу ч өөрчлөхгүй ("Байгууллагын нэр"-ийн "Заавал бөглөх"
  = Үгүй хэвээр).

  (Нэмэлт: өөр сонголтод ийм дүрэм хэрэгтэй бол CP Admin-ийн сонголтын
  мөрийн төгсгөлд "-> түлхүүр" бичиж болно, ж: "Тийм -> company".)

ШАЛГАХ:
  1. https://mglenc.com/registration нээгээд Ctrl+F5 дарна.
  2. "Ажил эрхэлж байгаа."-г сонгоход "БАЙГУУЛЛАГЫН НЭР *" болно.
  3. Байгууллагын нэргүй илгээхэд алдаа гарна; бичээд илгээхэд амжилттай.
  4. "Ажил эрхлээгүй." сонгоод байгууллагын нэргүй илгээхэд амжилттай.

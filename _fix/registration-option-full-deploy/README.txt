БҮРТГЭЛИЙН ФОРМ — СОНГОЛТЫГ "БҮРТГЭЛ ДҮҮРСЭН" БОЛГОЖ ТҮГЖИХ — суулгах заавар
==========================================================================

Юу нэмэгдэв:
  Бүртгэлийн формын сонголттой талбарт (checkbox / radio / select) аль нэг
  сонголтыг "дүүрсэн" гэж тэмдэглэж болно. Тэр сонголт:
    - текстээрээ харагдана (зурааслагдсан, бүдэг),
    - баруун талд нь "(Бүртгэл дүүрсэн)" гэж бичигдэнэ,
    - дарж сонгох боломжгүй (сервер тал дээр ч хүлээж авахгүй).

ХУУЛАХ (public_html дотор ЯГ ХЭВЭЭР нь, дарж хуулна):
  class/registration.class.php
  pages/registration/blocks/form.php
  cpadmin/pages/registration/field.frm.php
  assets/css/registration.css

  SQL, .htaccess, const.php — өөрчлөхгүй.

ТОХИРУУЛАХ (файл хуулсны дараа):
  1. CP Admin -> Бүртгэл -> Талбар тохируулах -> "Статус" талбарыг засах.
  2. "Сонголтууд" хэсэгт "Суралцаж байгаа." мөрийн ӨМНӨ ! тэмдэг тавина:
         !Суралцаж байгаа.
         Ажил эрхэлж байгаа.
         Ажил эрхлээгүй.
  3. Хадгална. Дахин нээх бол ! тэмдгийг арилгана.

ШАЛГАХ:
  1. https://mglenc.com/registration нээгээд формын СТАТУС хэсгийг харна.
  2. "Суралцаж байгаа. (Бүртгэл дүүрсэн)" гэж харагдаж, дарахад сонгогдохгүй.
     (Хуучнаараа байвал Ctrl+F5 дарж CSS-ийг шинэчилнэ.)
  3. Бусад хоёр сонголт хэвийн сонгогдож, бүртгэл амжилттай илгээгдэнэ.

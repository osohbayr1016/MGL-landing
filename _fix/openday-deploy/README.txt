OPEN OFFICE DAY — ЗОЧДЫН ТУР ХУУДАС (/openday) — суулгах заавар
=================================================================

Юуг шийдэж байгаа вэ:
  Өдөрлөгт ирсэн зочин QR уншуулаад нэг хуудаснаас бүх зүйлээ харна —
  хэнээс ч асуух шаардлагагүй:
    - Хөтөлбөр. Өдөрлөгийн өдөр "ОДОО" болон "ДАРАА НЬ" хэсэг дээд талд
      автоматаар гарна (Улаанбаатарын цагаар), өнгөрсөн хөтөлбөр бүдгэрнэ.
    - Хаана юу байна: 20F / 21F схем дээр өдөрлөгийн цэгүүд (бүртгэл,
      үзэсгэлэн, BIM демо, кофе, багууд ...). Хөтөлбөр, маршрут, мэдээллийн
      "байршил" товч дарахад схем рүү очиж, давхраа сольж, тэр цэг рүү ойртоно.
    - Хийж болох зүйлс — дугаарласан тур маршрут.
    - Практик мэдээлэл (WiFi, хувцасны өлгүүр, тусламж ...) + Түгээмэл асуулт.
    - MN / EN хэл солих товч (дээд баруун буланд).
  Харагдац нь бүртгэлийн хуудастай (/registration) ижил — тэр хуудасны
  дэвсгэр зураг, лого, өнгийг өөрөө уншина.

  Бүх агуулгыг CP Admin -> "Өдөрлөг" -> "Агуулга засах" хэсгээс засна.
  Анх нээхэд жишээ агуулгаар дүүрсэн байна — БОДИТ МЭДЭЭЛЛЭЭР СОЛИНО УУ
  (ялангуяа "Практик мэдээлэл" дэх [нэр], [нууц үг], [утасны дугаар]).

Шаардлага: PHP 7.2 (одоогийн сервер) — тохирно. .htaccess, const.php,
өгөгдлийн санг гараар засах ШААРДЛАГАГҮЙ (хүснэгтүүд анх хандахад өөрөө үүснэ).
Офис схем (/about) аль хэдийн суусан байх ёстой — зураг, viewer-ийг нь ашиглана
(2026-10-09-нд live дээр байгааг шалгасан).

     Хаяг яг "/openday" — ТӨГСГӨЛД "/" ТАВЬЖ БОЛОХГҮЙ (/openday/ нүүр хуудас руу орно).
  b) "Одоо / Дараа нь"-г өдөрлөгөөс өмнө шалгах:

     удирддаг) админд автоматаар нээгдэнэ. Бусад админд: Хандах эрх ->
     Эрхийн бүлэг -> "Өдөрлөг > Агуулга засах"-ыг чагтлана.


3. CP ADMIN-Д ЗАСАХ
-------------------
  Ерөнхий           — огноо, эхлэх/дуусах цаг, гарчиг, байршил, мэндчилгээ
  Хөтөлбөр          — цаг, гарчиг, тайлбар, байршил (схемийн цэг)
  Схемийн цэг       — давхраа сонгоод цэгийг чирж байрлуулна; "Цэг нэмэх"
                      дараад схем дээр дарж шинэ цэг тавина
  Хийж болох зүйлс  — маршрутын алхмууд (дарааллаар нь дугаарлагдана)
  Практик мэдээлэл  — icon + гарчиг + агуулга
  Түгээмэл асуулт   — асуулт / хариулт
  Мөр бүр: дээш/доош зөөх, устгах, "Харуулах" чагтыг авбал нуугдана.
  Монгол талбар заавал, англи хоосон бол англи горимд монголоороо гарна.
  Бүгдийг дуусгаад баруун дээд "Хадгалах" — нэг удаа дарахад бүгд хадгалагдана.
  Хоёр хүн зэрэг засаж байгаад хамгийн сүүлд хадгалсан нь нөгөөгийнхөө
  өөрчлөлтийг дарж бичихгүй — "Өөр хэн нэгэн хадгалсан" гэж анхааруулна.

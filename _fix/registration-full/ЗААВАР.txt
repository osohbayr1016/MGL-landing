  Зөвхөн extract хийнэ


ЭНЭ ХУВИЛБАРТ ЮУ ЗАССАН БЭ
---------------------------
Шинжилгээ: зураг байршуулах үед /registration руу явсан POST хүсэлт
HTTP 500 буцааж, JS нь "Сервер хариу буруу буцаалаа" гэж бичиж байсан.

  ШАЛТГААН
  pages/registration/sys.php нь байршуулсны дараа хариу бэлдэхдээ
  cdnUrl() функцийг дууддаг байв. Тэр функц сайтын functions.php-д
  байдаг ба СЕРВЕР ДЭЭР ХАРААХАН ОРООГҮЙ (өмнөх багцуудад орж
  байгаагүй). Тодорхойгүй функц дуудсан тул PHP fatal алдаа өгч,
  вэб сервер 500 буцаадаг байсан. Тэр 500-ын биед JSON биш HTML
  байсан тул хөтөч "хариу буруу" гэж бичиж байв.

  ЗАСВАР
  1. Модуль cdnUrl()-ээс хараат биш боллоо.
     RegistrationCore::mediaUrl() гэсэн өөрийн функц нэмсэн.
     Сайтын functions.php-д cdnUrl() байхгүй байсан ч ажиллана.

  2. AJAX хариу ОДОО ХЭЗЭЭ Ч HTML БУЦААХГҮЙ.
     Fatal алдаа гарсан ч JSON буцааж, жинхэнэ алдааны мессежийг
     хуудасны доод мөрөнд ХАРУУЛНА. Дахин "хариу буруу" гэж
     ойлгомжгүй бичихээ болино.

  3. Файлын хэмжээ, төрлийн алдааг ойлгомжтой болгосон:
       - серверийн upload_max_filesize / post_max_size-ыг уншиж,
         хэтэрсэн файлыг СЕРВЕР РҮҮ ЯВУУЛАХГҮЙГЭЭР зогсооно
       - "Файл хэт том (14 MB). Сервер дээд тал нь 2 MB хүлээж авна"
         гэх мэт тодорхой бичнэ
       - post_max_size хэтэрсэн үед ч (PHP бүх өгөгдлийг хаядаг)
         ойлгомжтой JSON өгнө
       - upload_tmp_dir алга / диск дүүрсэн / хавтас бичигдэхгүй
         тохиолдол бүрт өөр өөр мессеж

  4. cpadmin/postpic/reg/.htaccess-ийг ЗАССАН.
     Хуучин хувилбар нь "php_flag engine off" гэж ил бичдэг байсан.
     Энэ мөр нь PHP-FPM / CGI (LiteSpeed бус) сервер дээр ТЭР ХАВТСЫГ
     БҮХЭЛД НЬ 500 болгодог — өөрөөр хэлбэл байршуулсан зураг харагдахаа
     болих эрсдэлтэй байв. Одоо <IfModule> дотор хийж, бусад сервер
     дээр RemoveHandler + FilesMatch-аар хамгаална. Дараагийн
     байршуулалт хуучин файлыг автоматаар дарж бичнэ.

  5. cpadmin/r2.php БАГЦАД НЭМЭГДЛЭЭ (өмнө нь огт ороогүй).
     Ингэснээр CP Admin -> Тохиргоо доторх Cloudflare R2 талбарууд
     ЖИНХЭНЭЭР ажиллаж эхэлнэ. Хоосон орхивол зураг өмнөх шигээ
     сервер дээрээ хадгалагдана — юу ч эвдрэхгүй.

  6. Хөтөч дээрх алдааны бичиг HTTP статустай болсон, бүтэн хариуг
     console-д үлдээдэг боллоо (F12 -> Console).

3. ЗУРАГ БАЙРШУУЛАХЫГ ШАЛГАХ
-----------------------------
CP Admin -> Арга хэмжээний бүртгэл -> Хуудасны дизайн
-> баруун дээд булангийн "Хуудсан дээр нь засах"

  Ногоон хүрээтэй зураг дээр дарна -> "Зураг тавих"
  -> файлаа сонгоно -> доод мөрөнд хувь нь явна
  -> "Байршууллаа (сервер) — Хадгалах дарна уу" гарна
  -> "Хадгалах" дарна

Хэрэв алдаа гарвал доод мөрөнд ОДОО ЖИНХЭНЭ ШАЛТГААН бичигдэнэ,
жишээ нь:

  "Файл хэт том (14 MB). Сервер дээд тал нь 2 MB хүлээж авна."
      -> cPanel -> MultiPHP INI Editor -> upload_max_filesize болон
         post_max_size-ыг 64M болгоно (хоёуланг нь!)

  "cpadmin/postpic/reg хавтас бичигдэхгүй байна."
      -> File Manager -> cpadmin/postpic -> reg хавтасны эрхийг 0755

  "Серверт алдаа гарлаа. <жинхэнэ мессеж>"
      -> тэр мессежийг бүтнээр нь илгээнэ үү

  "Сервер хариу буруу буцаалаа (HTTP 403, сервер хүсэлтийг хаалаа)"
      -> mod_security. Хостоос /registration зам дээрх
         upload дүрмийг сулруулахыг хүснэ.


4. ЗУРАГ ХААНА ХАДГАЛАГДДАГ ВЭ
-------------------------------
Анхдагчаар:  public_html/cpadmin/postpic/reg/
Хаяг нь:     https://mglenc.com/pics/reg/<файл>

Cloudflare R2 руу хадгалуулах бол (заавал биш):
  CP Admin -> Арга хэмжээний бүртгэл -> Тохиргоо -> Медиа хадгалалт
    Account ID, Bucket, Access Key, Secret -> Хадгалах
    -> "R2 холболт шалгах" товч дарж бүх мөр OK эсэхийг харна
  CDN хаягийг хоосон орхивол зураг сервер дээрээ ч үлдэнэ (аюулгүй).

Хэрэв cpadmin/postpic/reg дотор хуучин .htaccess байгаад зураг
харагдахгүй байвал: дараагийн байршуулалт түүнийг автоматаар
зөв болгоно. Яаралтай бол тэр .htaccess-ийг устгаад дахин
нэг зураг байршуулна.


5. ХУУДСАН ДЭЭР НЬ ШУУД ЗАСАХ — САНАМЖ
---------------------------------------
  Цэнхэр тасархай хүрээ  = текст. Дээр нь дарж шууд бичнэ
  Ногоон хүрээ           = зураг. Дарж шинийг байршуулна
  Hero дэвсгэр           = дарж ЗУРАГ эсвэл ВИДЕО тавина
                           (видео нь давталттай background болно)
  Ctrl+S                 = хадгална
  "Гарах"                = засварлах горимоос гарна

Байршуулсны дараа ЗААВАЛ "Хадгалах" дарна — эс бөгөөс зураг
хуудсанд бэхлэгдэхгүй.

3. ХУУДСАН ДЭЭР НЬ ШУУД ЗАСАХ
-----------------------------
CP Admin -> Арга хэмжээний бүртгэл -> Хуудасны дизайн
-> баруун дээд булангийн "Хуудсан дээр нь засах" товч

Хуудас шинэ цонхонд засварлах горимоор нээгдэнэ:

  Цэнхэр тасархай хүрээ  = текст. Дээр нь дарж шууд бичнэ
  Ногоон хүрээ           = зураг. Дарж шинийг байршуулна
  Hero дэвсгэр           = дарж ЗУРАГ эсвэл ВИДЕО тавина
                           (видео нь давталттай background болно)
  Блок дээр хулгана      = дээш/доош зөөх, нуух/харуулах товч гарна
  Доод хар самбар        = Хадгалах (эсвэл Ctrl+S), Болих, Гарах

Хадгалаагүй байхад цонх хаавал анхааруулга гарна.

ХЭН ЗАСАХ ЭРХТЭЙ:
  - CP Admin-д нэвтэрсэн админ
  - Эсвэл дээрх товчны үүсгэсэн линкээр орсон хүн (24 цаг хүчинтэй)
  Зочид засварлагчийн юуг ч харахгүй (CSS, JS, атрибут аль нь ч гарахгүй).

АРГА ХЭМЖЭЭ ДУУСМАГЦ УНТРААХ:
  Тохиргоо -> "Хуудсан дээр нь шууд засварлах" -> Горим: Унтраасан
  Тэгвэл админ ч гэсэн хуудсан дээр засаж чадахгүй болно.


4. CLOUDFLARE R2 (заавал биш)
-----------------------------
R2-гүйгээр ч бүх зүйл ажиллана — зураг/видео серверийн диск дээр очно.

  Cloudflare дээр:
    1. R2 -> Create bucket -> нэр:  mglenc-media
    2. R2 -> Manage R2 API Tokens -> Create API token
       Permissions: Object Read & Write
       -> Access Key ID, Secret Access Key хуулж авна
    3. Account ID нь R2 хуудасны баруун талд

  CP Admin дээр:
    Арга хэмжээний бүртгэл -> Тохиргоо -> "Медиа хадгалалт — Cloudflare R2"
    -> 4 талбарыг бөглөж Хадгалах -> "Холболт шалгах" дарна

  Зургийг R2-оос үйлчлүүлэх (хурдан болгоно):
    cloudflare/media-worker.js -г deploy хийгээд (npx wrangler deploy)
    гарсан хаягийг "Медиа CDN хаяг" талбарт бичнэ

  CDN хаяг хоосон  -> зураг серверээс үйлчилнэ, R2-д хуулбар үлдэнэ
  CDN хаяг бичсэн  -> зөвхөн R2-оос үйлчилнэ, серверийн хуулбар устана

  const.php-д $gloR2Account гэх мэт бичсэн бол тэр нь давуу эрхтэй.

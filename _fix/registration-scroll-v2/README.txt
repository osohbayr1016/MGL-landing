ЭНЭ ХУВИЛБАРТ ЗАССАН ЗҮЙЛС
--------------------------

1) ХАР ЗУУРАЛТ АРИЛСАН
   Hero блок өөрийн бараан бүрхүүлтэй байсан тул hero дуусах ЯГ ТЭР
   шугам дээр хатуу хар зааг үүсдэг байв — дээд тал нь бараан, доод тал
   нь гэрэл. Одоо hero-д өөрийн бүрхүүл БАЙХГҮЙ. Бүх хуудсанд НЭГ жигд
   бүрхүүл байна:

       CP Admin -> Хуудасны дизайн -> "Бараан бүрхүүл (%)"

   Текст бүдэг байвал энэ хувийг нэмнэ (жишээ нь 55 -> 65).
   Ямар ч утга өгсөн зааг үүсэхгүй, учир нь бүрхүүл нь дэлгэцэнд
   наалдсан нэг давхарга.

2) ГҮЙЛТ ЗӨӨЛӨН БОЛСОН
   Өмнө нь хөтчийн CSS scroll-snap ашигладаг байсан. Хулганы дугуйны
   товшилт болгонд хуудас татагдаад цочромтгой мэдрэгддэг байв.

   Одоо:
     - Компьютер: дугуй эргүүлэх бүрд дараагийн хэсэг рүү 0.75 секундэд
       жигд гулсана (easing). Нэг шудралт = НЭГ шилжилт, trackpad-аар ч
       хэд хэдэн хэсэг алгасахгүй.
     - Гар утас: төрөлх гүйлт хэвээр — хуруугаараа гүйлгэх нь аль хэдийн
       зөөлөн, түүнийг хөндөөгүй.
     - Форм, урт хөтөлбөр гэх мэт дэлгэцээс ӨНДӨР хэсэг дотроо чөлөөтэй
       гүйнэ. Ирмэгт нь хүрсний дараа л дараагийн хэсэг рүү шилжинэ.
     - Хамгийн сүүлийн хэсгээс доош footer рүү чөлөөтэй гүйнэ.
     - PageUp / PageDown / Home / End товч ажиллана.

   Мөн snap асаалттай үед hero нь дэлгэц ДҮҮРЭН болно. Өмнө нь 90vh
   байсан тул доод талаас дараагийн хэсэг цухуйж харагддаг байв.

3) "ХӨТӨЛБӨР" ХЭСЭГ АВТОМАТААР НЭМЭГДЭНЭ
   Хуудсанд Хөтөлбөр (agenda) блок байхгүй бол системд НЭГ УДАА,
   "Арга хэмжээний мэдээлэл" хэсгийн ЯГ ДООР автоматаар нэмэгдэнэ.
   Гараар юу ч хийх шаардлагагүй — хуудсаа нээхэд л болно.

   (Нэг удаа. Дараа нь блокоо санаатай устгавал дахин ургахгүй.)


ХӨТӨЛБӨРӨӨ ХААНААС БИЧИХ ВЭ — 2 АРГА
-------------------------------------

АРГА 1. CP ADMIN-ААС (энгийн)

   CP Admin -> Арга хэмжээний бүртгэл -> Хуудасны дизайн
   -> "Хөтөлбөр (agenda)" блокийн ард байгаа харандаа (засах) товч
   -> "Хөтөлбөрийн агуулга" гэсэн ТОМ ТЕКСТ ТАЛБАР гарч ирнэ
      (үсгийн хэмжээ, өнгө, жагсаалт, хүснэгт бүхий бүрэн editor)
   -> Хадгалах

   Мөн тэр формд: гарчиг, хайрцгийн өргөн, байрлал, дэвсгэр өнгө,
   тунгалаг, дотоод зай тохируулна.

   Цагийн хуваарийн мөрүүд (timeline) нь блокийн ДЭД МӨР —
   "Мөр нэмэх" товчоор нэмж, Цаг / Огноо / Байршил / Агуулга бөглөнө.


АРГА 2. ХУУДСАН ДЭЭРЭЭ ШУУД (текст засах багаж энд байна)

   ЭНЭ БАГАЖ ЗӨВХӨН ЗАСВАРЛАХ ГОРИМД ГАРНА. Энгийн зочны харагдацаар
   хуудсыг нээвэл ямар ч засварын хэрэгсэл харагдахгүй — энэ нь зөв.

   Засварлах горимд орох:

       CP Admin -> Арга хэмжээний бүртгэл
       -> баруун дээд буланд "Хуудсан дээр нь засах" (шар товч)

   эсвэл

       CP Admin -> Хуудасны дизайн
       -> баруун дээд буланд "Хуудсан дээр нь засах"

   Товч дарахад хуудас ШИНЭ ЦОНХОНД нээгдэж, доод талд хар мөр
   (MGL ... Хадгалах / Болих / Дэвсгэр / Гарах) гарч ирнэ. Тэр мөр
   харагдаж байвал засварлах горимд орсон гэсэн үг.

   Тэр горимд:
     - Хөтөлбөрийн текст дээр дарна -> дээр нь хөвөгч багаж гарч ирнэ:
         Хэмжээ | Загвар | Тод / Налуу / Доогуур | Өнгө
         Жагсаалт | Зэрэгцүүлэлт | Холбоос | Цэвэрлэх
     - Хайрцгийн баруун дээд буланд байгаа шилжүүлэгч товчоор:
         Байрлал, Өргөн, Дотоод зай, Дэвсгэр өнгө, Тунгалаг
     - Дэвсгэр зураг/видео солих: доод мөрний "Дэвсгэр" товч, эсвэл
       hero зураг дээр шууд дарах
     - Дуусмагц "Хадгалах" (эсвэл Ctrl+S)

   АНХААР: хөвөгч багаж нь ЧӨЛӨӨТ АГУУЛГЫН талбаруудад гарна
   (Хөтөлбөрийн агуулга, цагийн хуваарийн агуулга, Текст блок).
   Гарчиг, огноо, байршил зэрэг нь энгийн текст тул зөвхөн үг нь
   солигдоно — тэдгээрийн хэмжээ, өнгийг CP Admin -> Хуудасны дизайн
   -> Загвар хэсгээс бүх хуудсанд нэг дор тохируулна.

2. ДЭВСГЭР ЗУРАГ
----------------
Дэвсгэр нь бүх хуудсанд ТОГТМОЛ — гүйлгэхэд зураг байрандаа үлдэж,
зөвхөн текст нь дээгүүр нь хөвнө.

  CP Admin -> Хуудасны дизайн -> "Хуудасны дэвсгэр — зураг / видео"
      Дэвсгэр зураг / Дэвсгэр видео
      Бараан бүрхүүл (%)      <- текст бүдэг байвал энэ хувийг нэмнэ
      Бүдгэрүүлэх (px)
      Зургийн байрлал

Хуучин Hero зураг/видеог систем нэг удаа автоматаар шилжүүлж авсан.


3. ГҮЙЛТИЙН ТОХИРГОО
--------------------
CP Admin -> Хуудасны дизайн -> "Гүйлт (scroll)"

  Хэсэг бүр дэлгэц дүүрэн   — зөөлөн гулсалтыг асаах/унтраах
  Баруун талын цэгэн цэс    — хэсэг сонгох цэгүүд

Унтраавал энгийн, чөлөөт гүйлт болно.

=========================================================================

Энэ багц нь /registration хуудсанд хийсэн ШИНЭЧЛЭЛТИЙГ агуулна.

  1) Дэвсгэр зураг/видео нь БҮХ ХУУДСАНД ТОГТМОЛ зогсоно.
     Доошоо гүйлгэхэд зураг байрандаа үлдэж, зөвхөн текст нь
     дээгүүр нь хөвж өнгөрнө.

  2) Хэсэг бүр дэлгэц дүүрэн snap хийж, текст нь доороосоо зөөлөн
     гарч ирээд БАЙРАНДАА үлдэнэ (өмнө нь алга болдог байсан).

  3) Хөтөлбөрийн хэсэг = timeline (цаг зүүн талд) + доор нь тусдаа
     "Хөтөлбөр" хайрцаг. Тэр хайрцаг доторх текстээ хуудсан дээрээ
     шууд засаж, үсгийн хэмжээ / өнгө / загвар / байрлалыг нь
     өөрчилнө.

  SQL ажиллуулах        ШААРДЛАГАГҮЙ  (шинэ тохиргоо автоматаар нэмэгдэнэ)
  .htaccess засах       ШААРДЛАГАГҮЙ
  Зөвхөн extract хийнэ

2. ДЭВСГЭР ЗУРАГ ХААНА БАЙХ ВЭ
------------------------------
Өмнө нь дэвсгэр зураг HERO блок дотор байсан бөгөөд хуудастайгаа
хамт доошоо гүйдэг байлаа. Одоо тэр нь ХУУДАСНЫ тохиргоо болсон.

  * Хуучин Hero зураг/видеог систем НЭГ УДАА автоматаар шилжүүлж
    авна. Гараар юу ч хийх шаардлагагүй.

  * Солих 2 арга:
      CP Admin -> Хуудасны дизайн -> "Хуудасны дэвсгэр — зураг / видео"
      эсвэл  /registration?edit=... горимд доод мөрний "Дэвсгэр" товч
      (эсвэл hero зураг дээр шууд дарах)

  * Тохируулж болох зүйлс: зураг, видео, бараан бүрхүүл (%),
    бүдгэрүүлэлт (px), зургийн байрлал.


3. ХӨТӨЛБӨРИЙН ХЭСЭГ
--------------------
CP Admin -> Хуудасны дизайн -> "Хөтөлбөр (agenda)" блок:

  Дэд мөр бүр = timeline-ийн нэг мөр
      Цаг / Огноо / Байршил / Агуулга

  Блокийн талбарууд = доод "Хөтөлбөр" хайрцаг
      Доод хэсгийн гарчиг, Агуулга, Байрлал, Өргөн, Дэвсгэр өнгө,
      Тунгалаг, Дотоод зай

ХУУДСАН ДЭЭРЭЭ ШУУД ЗАСАХ (хамгийн хялбар):

  1) Хөтөлбөрийн текст дээр дарна -> дээр нь багаж гарч ирнэ:
        Хэмжээ | Загвар | Тод/Налуу/Доогуур | Өнгө
        Жагсаалт | Зэрэгцүүлэлт | Холбоос | Цэвэрлэх
  2) Хайрцгийн баруун дээд буланд байгаа шилжүүлэгч (sliders) товчоор:
        Текстийн зэрэгцүүлэлт, Хайрцгийн байрлал, Өргөн,
        Дотоод зай, Дэвсгэр өнгө, Тунгалаг
  3) Доод мөрний "Хадгалах" (эсвэл Ctrl+S)


4. ГҮЙЛТИЙН ТОХИРГОО
--------------------
CP Admin -> Хуудасны дизайн -> "Гүйлт (scroll)"

  Хэсэг бүр дэлгэц дүүрэн   — snap асаах/унтраах
  Баруун талын цэгэн цэс    — хэсэг сонгох цэгүүд

Дэлгэцээс ӨНДӨР хэсэг (форм, урт хөтөлбөр) snap-аас автоматаар
чөлөөлөгдөнө — эс бөгөөс уншиж дуусгах боломжгүй болно.


5. ШАЛГАХ
---------
  - https://YOUR-DOMAIN/registration нээнэ
  - Доошоо гүйлгэнэ -> дэвсгэр зураг БАЙРАНДАА үлдэнэ, текст л хөдөлнө
  - Хэсэг бүр дэлгэц дүүрэн зогсоно, баруун талд цэгүүд идэвхжинэ
  - Хөтөлбөр: timeline дээр, доор нь "Хөтөлбөр" хайрцаг
  - Гар утсан дээр: timeline нэг баганад буух, цэгэн цэс нуугдана
  - Live edit (?edit=...) -> текст дээр дарж багажаар засах, Хадгалах

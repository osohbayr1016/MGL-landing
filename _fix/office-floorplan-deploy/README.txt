ОФИС ХУУДАСНЫ ИНТЕРАКТИВ ДАВХРЫН СХЕМ (20, 21-р давхар) — суулгах заавар
=======================================================

Юуг шийдэж байгаа вэ:
  Сайтын "ОФФИС" (/about) хуудасны эхний хэсгийн (Профайл) зургийн баннерыг
  интерактив давхрын схемээр солино.
    - 20-р давхар (11 цэг) ба 21-р давхар (5 цэг) тус тусдаа; дээд талд давхрын гарчиг
    - Гарчиг ("20-Р ДАВХАР  ↑ 21") эсвэл схем дээрх ШАТНЫ тэмдэг дээр дарахад
      камер шат руу орж, давхар доошоо холдон, нөгөө давхар шатнаасаа гарч ирнэ
    - Цэг дарахад камер тэр цэг рүү ойртож, нэр (EN/MN) болон тайлбар гарна
    - Зүүн / доош / баруун сум: өмнөх, бүгдийг харах, дараах (гар утсанд swipe)
    - Схемийг чөлөөтэй "аялж" үзнэ: хулганаар чирэх, гүйлгэж (wheel) томруулах,
      хоёр дарж томруулах; гар утсанд хуруугаар чирэх, хоёр хуруугаар томруулах.
      Ойртоход өрөөний нэр цэгийн хажууд гарна. Бүрэн жижигрүүлсэн үед
      гүйлгэхэд хуудас доошоо гүйлгэгдэнэ (зочин гацахгүй)
    - ?area=kitchen гэх мэтээр тодорхой өрөөг шууд нээх линк (зөв давхар нь
      автоматаар нээгдэнэ), ?floor=21 — 21-р давхрыг шууд нээнэ
  CP Admin -> "Офис схем" цэснээс бүх агуулгыг засна (дэлгэрэнгүй доор):
    давхрын гарчиг, өрөөний нэр (англи / монгол), тайлбар (монгол / АНГЛИ),
    цэгийн байршил, шатны байршил, камерын тохиргоо, харуулах / нуух.
  Сайтын англи хувилбар (/EN) дээр англи тайлбар гарна (хоосон бол монгол).

  Ямар нэг алдаа гарвал (хүснэгт, файл дутуу, цэг идэвхгүй г.м.) хуучин
  зургийн баннер хэвээр гарна — Офис хуудас хэзээ ч эвдрэхгүй.

Шаардлага: PHP 7.2 (одоогийн сервер) — тохирно. composer, node, шинэ сан ХЭРЭГГҮЙ.

2. CP ADMIN-ий ЗАМ (cpadmin/.htaccess) — гараар 2 мөр нэмнэ
-----------------------------------------------------------
cpadmin/.htaccess дотор
    RewriteRule ^pics/([A-Z,a-z]+)/([^/]+)(/?) postpic/$1/$2 [NC,L]
гэсэн мөрийн ӨМНӨ дараах 2 мөрийг нэмнэ:

  RewriteRule ^floorplan/asset/([^/]+)(/?)$ index.php?incPageType=floorplan&subPage=asset&asset=$1 [L,QSA]
  RewriteRule ^floorplan/([^/]+)(/?) index.php?incPageType=floorplan&subPage=$1 [L,QSA]

(.htaccess-ийг бүтнээр нь солихгүй — cPanel-ийн PHP тохиргооны мөрүүд байдаг.)


3. ӨГӨГДЛИЙН САН
----------------
Юу ч хийх шаардлагагүй. /about хуудсыг анх нээхэд (эсвэл CP Admin -> Офис схем)
дараах 2 хүснэгт АВТОМАТААР үүсч, 2 давхар, 16 цэгээр дүүрнэ:

  db_floorplan            давхар бүр нэг мөр: гарчиг, зураг, шатны байршил,
                          идэвхтэй эсэх, revision
  db_floorplan_hotspot    цэг бүр: slug, дараалал, нэр EN/MN, тайлбар, x/y (0..1),
                          компьютерын болон гар утасны камерын тохиргоо

Өгөгдлийн сангийн хэрэглэгчид CREATE TABLE эрх хэрэгтэй (Дадлагын модуль адил).
Үүсгэж чадахгүй бол сайт өгөгдмөл 16 цэгээр ажиллана, харин CP Admin дээр
улаан анхааруулга гарна.


4. ЭРХ (чухал)
--------------
"Офис схем" засах эрх нь "floorplan_edit". Нэвтрээгүй хүн, эсвэл эрхгүй админ
(цэс нууцлагдсан эсэхээс үл хамааран) засах боломжгүй — сервер талд шалгагдана.

  - "Хандах эрх" (access) удирддаг админд автоматаар нээгдэнэ.
  - Бусад админд: CP Admin -> Хандах эрх -> Эрхийн бүлэг -> бүлгээ засаж
    "Офис схем > Цэг, тайлбар засах" эрхийг нэмнэ.

6. ЦЭГ ЗАСАХ ЗААВАР (CP Admin -> Офис схем)
-------------------------------------------
  - Схемийн дээд талын "20-Р ДАВХАР / 21-Р ДАВХАР" табаар давхраа сонгоно.
    Хоёр давхрын өөрчлөлт нэг "Хадгалах" товчоор хамт хадгалагдана.
  - Баруун талын "Цэгүүд" жагсаалтаас цэгээ сонгоно (эсвэл схем дээрх цэг дээр дарна).
  - ШАТ: схем дээрх шатны тэмдгийг (⤴) чирж давхар хоорондын шатан дээр байрлуулна.
  - БАЙРШИЛ: цэгийг схем дээр шууд ЧИРНЭ. Нарийн засах бол цэг дээр дарж
    (фокус авсан үед) сумны товч (Shift = 10 дахин том алхам) эсвэл X/Y талбар.
    "Буцаах" нь сүүлийн чирэлтийг буцаана.
  - НЭР, ТАЙЛБАР: English / Монгол нэр, "Тайлбар — монгол" (сайтын монгол
    хувилбар) ба "Description — English" (сайтын англи хувилбар) талбарт бичнэ.
    Зүүн талын схем дээр шууд шинэчлэгдэнэ.
  - КАМЕР: "Компьютерын камер" ба "Гар утасны камер" хэсэгт
      Zoom (1.2–16)           — хэр ойртох
      Offset X / Y             — цэгийг дэлгэцийн хаана байрлуулах (карт, сумны
                                 доор нуугдахгүйн тулд). 0 = өгөгдмөл байрлал
      Фокус цэг                — камер цэгээс өөр газрыг төвлөх бол
    Утга өөрчлөх бүрт зүүн талд тэр төхөөрөмжийн (1440x780 / 390x780)
    жинхэнэ харагдац шууд шинэчлэгдэнэ. "Бүтэн схем / Компьютер / Гар утас"
    товчоор харагдацаа сольж үзнэ.
  - ШИНЭ ЦЭГ: "Цэг нэмэх" -> схем дээр дарна -> нэр, slug (a-z, 0-9, -) бичнэ.
    Хувилах, дараалал солих (↑↓), идэвхгүй болгох, устгах товчууд баруун талд.
    Сумаар дарахад очих дараалал нь жагсаалтын дараалал.
  - "Давхар" хэсэгт тухайн давхрын гарчиг ("20-Р ДАВХАР") болон тэр давхрыг Офис
    хуудсанд харуулах эсэхийг тохируулна. Нэг давхрыг унтраавал нөгөө нь л гарна.
  - ХАДГАЛАХ товч дарах хүртэл юу ч нийтэд гарахгүй. Хадгалаагүй өөрчлөлттэй
    байхад хуудсыг хаах гэвэл анхааруулна. Хэрэв өөр хүн дундуур хадгалсан бол
    "Өөр хэн нэгэн хадгалсан" гэж мэдэгдэж, таны засвар алга болохгүй.
  - Хуучин slug (жишээ нь kitchen) нь ?area=kitchen линкэнд ашиглагддаг тул
    өөрчлөх боломжгүй; шинэ цэгийн slug-ийг л анх үүсгэхэд зааж өгнө.


7. БУЦААХ (хэрэв яаралтай хуучин байдалд оруулах бол)
----------------------------------------------------
widgets/pagesch/temp.php-ийг нөөцөлсөн хуучин хувилбараар нь солино — Офис
хуудас дахин хуучин зургийн баннертай болно. Бусад файл, хүснэгтийг устгах
шаардлагагүй. (Түр унтраах бол CP Admin -> Офис схем дээр хоёр давхрын
"Энэ давхрыг Офис хуудсанд харуулах" тэмдгийг авч хадгална.)


ШАЛГАСАН ЗҮЙЛС (deploy-оос өмнө)
-------------------------------
- PHP 7.2.34 (серверийн хувилбар) дээр: синтакс, бүх PHP тест, мөн жинхэнэ
  CP Admin (нэвтрэх, цэс, эрхийн бүлэг, засварлагч, хадгалах) — алдаагүй.
- MariaDB дээр хүснэгт автоматаар үүсэх, хадгалах, хоёр хүн зэрэг засах үеийн
  хамгаалалт, алдаа гарвал бүгдийг буцаах (rollback).
- Эрхгүй админ / нэвтрээгүй хүн засах, файл татах боломжгүй (сервер талд 403).
- Хөтөч дээр: компьютер, таблет, гар утасны 8 хэмжээ; давхар солих, чирэх,
  томруулах, өрөө нээх, гар (keyboard) удирдлага, англи хувилбар.

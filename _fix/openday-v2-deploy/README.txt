OPEN OFFICE DAY (/openday) — 2-р хувилбар — суулгах заавар
==========================================================

Өмнөх "openday-deploy" суусан сервер дээр ДАРЖ хуулна. Оруулсан агуулга
(хөтөлбөр, цэг, мэдээлэл, асуулт) АЛДАГДАХГҮЙ.

Юу өөрчлөгдөж байгаа вэ:

  1. Хэсэг бүр ТУСДАА ХУУДАС боллоо
       /openday               — нүүр: гарчиг, огноо, "Одоо / Дараа нь",
                                хэсгүүд рүү орох 4 товчлуур
       /openday?p=schedule    — зөвхөн хөтөлбөр
       /openday?p=map         — зөвхөн схем
       /openday?p=info        — зөвхөн практик мэдээлэл
       /openday?p=faq         — түгээмэл асуулт + асуулт асуух
     Дээд цэс дарахад хуудас дахин ачаалагдахгүй шилжинэ, "буцах" товч ажиллана.
     Байршлын товч (жишээ нь хөтөлбөрийн мөр дээрх) схем хуудас руу орж тэр цэгийг нээнэ.

  2. "Хийж болох зүйлс" хэсгийг хассан (өгөгдөл нь устаагүй, зүгээр харагдахгүй).

  3. АСУУЛТ АСУУХ: "Асуулт" хуудасны доод талд зочин асуултаа бичиж илгээнэ.
     CP Admin -> Өдөрлөг -> "Ирсэн асуулт" хуудсанд хэдхэн секундэд ӨӨРӨӨ гарч ирнэ
     (хуудсыг дахин ачаалах шаардлагагүй, browser tab дээр шинэ асуултын тоо,
     хүсвэл дуут дохио). "Хариулсан" гэж тэмдэглэх, устгах боломжтой.
     Хамгаалалт: robot-ын урхи, нэг хүнээс 10 минутад 5-аас олон асуулт авахгүй.
     Асуулт хүлээн авахыг "Хуудас засах" -> Асуулт хуудсан дээрх чагтаар унтраана.

  4. ХУУДСАН ДЭЭР НЬ ЗАСАХ: CP Admin -> Өдөрлөг -> "Хуудас засах" нь одоо
     /openday хуудсыг ЯГ харагдах байдлаар нь харуулна:
       - Текст дээр дарж шууд бичнэ (дээд талын MN / EN товчоор хэлээ сольж засна)
       - Мөр дээр очиход: ↑ ↓ (дараалал), нүд (зочдод нуух/харуулах), хогийн сав (устгах)
       - "+ Хөтөлбөр нэмэх", "+ Карт нэмэх", "+ Асуулт нэмэх" товч
       - Огноо, цаг, байршил, icon, давхар дээр дарахад сонгох цонх гарна
       - Цаг бичихэд "1430" гэвэл 14:30 болно
       - Схем дээр цэгийг чирж байрлуулна, "Цэг нэмэх" дараад схем дээр дарна,
         давхар солихдоо схемийн дээд талын "20F ↑ 21" дээр дарна
       - Хэсгийн гарчгууд ("Хөтөлбөр", "Хаана юу байна" ...) ч засагдана
       - Компьютер / гар утасны харагдацаар шалгах товч
       - Бүгдийг дуусгаад баруун дээд "Хадгалах" (хадгалаагүй бол "Болих")

Шаардлага: PHP 7.2 — тохирно. .htaccess, const.php засах ШААРДЛАГАГҮЙ.
Шинэ хүснэгт db_openday_question анх хандахад өөрөө үүснэ.

2. ШАЛГАХ
---------
  a) https://mglenc.com/openday — нүүр хуудас; товчлуур/цэсээр хуудас бүр руу орно.
  b) https://mglenc.com/openday?p=faq — доод талд асуулт бичээд "Илгээх".
  c) CP Admin -> Өдөрлөг -> Ирсэн асуулт — тэр асуулт хэдхэн секундэд гарч ирнэ.
  d) CP Admin -> Өдөрлөг -> Хуудас засах — хуудас дээр дарж засаад "Хадгалах",
     дараа нь /openday дээр өөрчлөлт гарсныг шалгана.
  e) "Хандах эрх"-тэй админд хоёр цэс автоматаар нээгдэнэ. Бусад админд:
     Хандах эрх -> Эрхийн бүлэг -> "Өдөрлөг > Хуудас засах" / "Өдөрлөг > Ирсэн асуулт".
     (Жишээ нь хүлээн авалтын ажилтанд зөвхөн "Ирсэн асуулт"-ыг өгч болно.)
  f) "Одоо / Дараа нь"-г урьдчилан шалгах: https://mglenc.com/openday?at=12:40

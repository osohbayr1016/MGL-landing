ХУУДСАН ДЭЭР НЬ ШУУД ЗАСВАРЛАХ + CLOUDFLARE R2
================================================

Энэ бол ШИНЭЧЛЭЛТ. Бүртгэлийн модуль аль хэдийн суусан байх ёстой.

  SQL ажиллуулах ШААРДЛАГАГҮЙ
  .htaccess засах ШААРДЛАГАГҮЙ
  Зөвхөн доорх файлуудыг дарж бичнэ

2. ХЭРХЭН АШИГЛАХ
-----------------
  1. CP Admin -> Арга хэмжээний бүртгэл -> Хуудасны дизайн
  2. Баруун дээд булангийн "Хуудсан дээр нь засах" товчийг дарна
  3. Бүртгэлийн хуудас ШИНЭ ЦОНХОНД засварлах горимоор нээгдэнэ

Тэнд:
  - Цэнхэр тасархай хүрээтэй БҮХ ТЕКСТ дээр дарж шууд бичнэ
  - Ногоон хүрээтэй ЗУРАГ дээр дарж шинийг байршуулна
  - Hero-гийн ДЭВСГЭР дээр дарж зураг ЭСВЭЛ ВИДЕО тавина
    (видео сонговол автоматаар давталттай background видео болно)
  - Блок дээр хулганаа аваачихад дээр нь товчнууд гарна:
    дээш / доош зөөх, нуух / харуулах
  - Доод талын хар самбараас "Хадгалах" дарна (эсвэл Ctrl+S)
  - "Гарах" дарвал энгийн горимд буцна

Хадгалаагүй байхад цонх хаавал анхааруулга гарна.


3. ХЭН ЗАСАЖ ЧАДАХ ВЭ
---------------------
  - CP Admin-д нэвтэрсэн админ  (mglenc.com/cpadmin дээр нэвтэрсэн бол
    хуудсыг шууд нээхэд л засварлах горим идэвхжинэ)
  - Эсвэл "Хуудсан дээр нь засах" товчны үүсгэсэн линкээр орсон хүн
    (линк 24 цаг хүчинтэй)

Зочид энэ бүхнийг ОГТ ХАРАХГҮЙ. Тэдэнд засварлагчийн CSS/JS
ачаалагдахгүй, засварлах атрибут ч HTML-д гарахгүй.


4. АРГА ХЭМЖЭЭ ДУУСМАГЦ УНТРААХ
-------------------------------
CP Admin -> Арга хэмжээний бүртгэл -> Тохиргоо
-> "Хуудсан дээр нь шууд засварлах" -> Горим: "Унтраасан" -> Хадгалах

Унтраасны дараа админ ч гэсэн хуудсан дээр засаж чадахгүй болно
(зөвхөн CP Admin-аас). Дахин асаах бол мөн тэндээс.


5. CLOUDFLARE R2 ТОХИРУУЛАХ
---------------------------
R2-гүйгээр ч бүх зүйл ажиллана — зураг/видео серверийн диск дээр
хадгалагдана. R2 залгавал:

  Cloudflare дээр:
    1. R2 -> Create bucket -> нэр:  mglenc-media
    2. R2 -> Manage R2 API Tokens -> Create API token
       -> Permissions: Object Read & Write
       -> Access Key ID болон Secret Access Key-г хуулж авна
    3. Account ID нь R2 хуудасны баруун талд бичээстэй

  CP Admin дээр:
    Арга хэмжээний бүртгэл -> Тохиргоо -> "Медиа хадгалалт — Cloudflare R2"
    -> Account ID, Bucket нэр, Access Key ID, Secret Access Key оруулна
    -> Хадгалах -> дараа нь "Холболт шалгах" дарж баталгаажуулна

  Зургийг R2-оос үйлчлүүлэх (заавал биш, гэхдээ хурдан):
    1. cloudflare/media-worker.js болон wrangler.toml -г ашиглан
       worker deploy хийнэ:   npx wrangler deploy
    2. Гарсан хаягийг (жишээ: https://mglenc-media.xxx.workers.dev)
       Тохиргооны "Медиа CDN хаяг" талбарт бичнэ

  CDN хаяг ХООСОН үед:  зураг серверээс үйлчилнэ, R2-д хуулбар үлдэнэ
  CDN хаяг ОРУУЛСАН үед: зөвхөн R2-оос үйлчилнэ, серверийн хуулбар устана

  Анхаар: R2 тохиргоог const.php-д бичсэн бол ($gloR2Account гэх мэт)
  тэр нь давуу эрхтэй бөгөөд CP Admin дахь талбарууд ашиглагдахгүй.


6. АЮУЛГҮЙ БАЙДАЛ
-----------------
  - Байршуулах файлыг цагаан жагсаалтаар шүүнэ: jpg png webp gif svg
    mp4 webm mov ogv. Бусад бүх өргөтгөл (php, phtml, sh, html ...)
    болон давхар өргөтгөл (a.php.jpg) хаагдана
  - Зургийн агуулгыг getimagesize-ээр бас шалгана
  - cpadmin/postpic/reg/ хавтсанд .htaccess автоматаар үүсч, тэнд
    ямар ч скрипт ажиллахгүй болгоно
  - Хадгалах бүрд session-д уягдсан нэг удаагийн түлхүүр шалгагдана (CSRF)
  - Зөвхөн блокийн каталогт бүртгэлтэй талбарууд бичигдэнэ —
    blockStatus, parentID, r2Secret зэргийг гаднаас өөрчлөх боломжгүй
  - Файлын дээд хэмжээ 200 MB (сервер өөрөө үүнээс бага хязгаартай байж болно —
    хэрэв том видео орохгүй бол php.ini дахь upload_max_filesize,
    post_max_size утгыг нэмэгдүүлнэ)
